# ポケットモンスター 赤 3D (Pokemon Red 3D MVP)

Three.js と Web Audio API を駆使して制作された、HTML/CSS/JS のみ（`index.html` 1ファイル）で動く「ポケットモンスター 赤」のレトロ3D MVPです。

## 🌟 ゲーム概要・特徴

- **完全1ファイル完結 (`index.html`)**: 外部画像アセットに依存せず、Three.js のプロシージャルローポリ・ボクセル技術でキャラクターや世界を構築。ロードエラー皆無で軽量動作します。
- **レトロ3Dマサラタウン & 1番道路**:
  - 主人公レッド、オーキド博士、レッドの家、ライバルの家、ポケモン研究所、木々、草むら、柵、海などを完全3D化。
  - 看板を読んだり、自宅のママに話しかけるとポケモンが全回復。
- **草むらエンカウント & ターン制コマンドバトル**:
  - 1番道路の草むらを歩くと野生ポケモン（ポッポ、コラッタ、ピカチュウ）とエンカウント！
  - 相棒「ヒトカゲ」で「たたかう（ひのこ、ひっかき、たいあたり）」、「バッグ」、「にげる」。
  - 「モンスターボール」を投げて野生ポケモンの捕獲が可能！捕獲したポケモンは手持ちに加わります。
  - 経験値獲得とレベルアップシステム搭載。
- **8-Bit レトロチップチューン サウンド**:
  - Web Audio API シンセサイザーによるマサラタウンBGM、戦闘曲、効果音（打撃、炎、ボール揺れ、捕獲ファンファーレ、レベルアップ音等）。
- **マルチデバイス対応**:
  - PC（キーボード操作）および スマートフォン（画面上のゲームボーイ風D-Pad・A/Bボタン）。

## 🎮 操作方法

| ボタン | キーボード | 画面タッチ |
| :--- | :--- | :--- |
| **移動** | 矢印キー / W, A, S, D | 十字キー (▲ ◀ ▶ ▼) |
| **Aボタン (決定 / 調べる / 話す)** | Z / J / Enter | Aボタン |
| **Bボタン (キャンセル / もどる)** | X / K / Shift | Bボタン |
| **START (メニュー開閉)** | C / Escape | STARTボタン |
